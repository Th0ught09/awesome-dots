# AwesomeWM

- Dotfiles for my [awesome](https://github.com/awesomeWM/awesome) config

## installation

- it is recommended to backup an old config first

```bash
if [[ -d ~/.config/awesome ]]; then
    mv ~/.config/awesome{,-$(date +%Y-%m-%d).bak}
fi
git clone https://github.com/Th0ught09/awesome-dots.git ~/.config/awesome
```
